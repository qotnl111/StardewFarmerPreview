# 🧑‍🌾 Stardew Farmer Previewer (스타듀밸리 파머 리텍스쳐 모션 프리뷰어)

스타듀밸리의 플레이어 캐릭터(파머, Farmer)의 리텍스쳐(신체, 헤어, 셔츠, 바지, 액세서리)를 인게임에 접속하지 않고도 웹 브라우저에서 실시간으로 조합하고, 58종의 전방향 액션/도구 모션을 즉각 검수할 수 있는 **단일 무설치(Standalone Single-File) HTML5 웹 애플리케이션**입니다.

- **실행 파일**: `StardewFarmerPreview.html`
- **현재 버전**: `v2.1`
- **기술 스택**: 순수 HTML5 Canvas, Vanilla ES6+ JavaScript, CSS3 Flexbox/Grid (외부 라이브러리 및 종속성 0개, 100% 로컬 구동)

---

## 1. 기획 목적 및 배경 (Purpose)

1. **인게임 리텍스쳐 검수의 피로도 해소**:
   - 스타듀밸리 파머의 의상(셔츠, 바지)이나 헤어, 바디 리텍스쳐를 제작할 때, 도트가 제대로 맞물리는지 확인하려면 매번 게임을 켜고, 캐릭터를 움직이고, 도구를 휘두르는 번거로운 과정을 거쳐야 했습니다.
2. **도트 정렬 및 모션 결함 조기 발견**:
   - 걷기, 달리기, 낚시, 물주기, 도구 스윙, 무기 공격 등 58가지 동작에서 헤어와 셔츠가 신체 베이스와 1픽셀이라도 어긋나는지 2x~10x 고배율 픽셀 아트로 즉시 확인할 수 있습니다.
3. **완전 무설치 단일 파일 & 다국어 글로벌 지원**:
   - 복잡한 빌드나 서버 없이 `.html` 파일 하나만 더블 클릭하면 오프라인에서도 즉시 작동합니다.
   - 넥서스 모드(Nexus Mods) 배포 및 글로벌 모더들을 고려하여 **한국어, 영어(English), 중국어(中文), 일본어(日本語)** 4개 국어 실시간 변환을 완벽 지원합니다.

## 2. 주요 기능 및 인게임 재현 스펙 (Key Features)

### (1) 완벽한 파머 레이어 합성 엔진 (Vanilla Farmer Rendering Layering)
바닐라 스타듀밸리 엔진의 파머 드로잉 순서를 100% 충실히 구현:
1. **신체 베이스 (`farmer_base.png` / `farmer_girl_base.png`)**: 남성/여성 체형 베이스.
2. **바지 레이어 (`pants.png`)**: 기본 긴바지, 반바지, 치마 등 바지 텍스처 오버레이 및 색상 틴트(Dye).
3. **셔츠 레이어 (`shirts.png`)**: 반팔, 긴팔, 조끼 등 셔츠 스프라이트 및 사용자 정의 색상 틴트.
4. **눈동자 및 피부톤**: 24색 피부 톤 및 사용자 지정 눈 색상(RGB) 렌더링.
5. **헤어 레이어 (`hairstyles.png`)**: 헤어스타일 1~56번 및 1.6 신규 헤어 완벽 탐색, 헤어 컬러 염색 지원.

### (2) 58종 전방향 모션 애니메이션 완벽 수록
바닐라 파머의 모든 모션을 7대 카테고리로 체계화하여 1클릭 프리뷰 제공:
- **기본 이동**: 걷기 (하/우/상/좌), 달리기 (하/우/상/좌)
- **도구 사용**: 도구 휘두르기 (하/우/상/좌), 물뿌리개 주기 (하/우/상/좌)
- **전투 및 무기**: 한 손 검 휘두르기, 대검 내려치기, 찌르기, 가드/막기
- **특수 활동**: 낚시 캐스팅, 입질 대기, 릴 감기, 보물 낚아채기
- **농장 활동**: 수확하기, 씨앗 뿌리기, 먹기/마시기 (4단계)
- **감정 표현 (Emotes)**: 인사하기, 하트 띄우기, 물음표, 느낌표, 춤추기 등

### (3) 정밀 검수 도구 세트
- **줌 배율**: 2x, 3x, 4x, 6x, 8x, 10x 네이티브 Nearest-Neighbor 픽셀 스케일링.
- **재생 제어**: 일시정지, 프레임 단위 넘기기(Next Frame), 재생 속도 조절 (0.25x 슬로우 모션 ~ 2.0x 고속).
- **시각 보조**: 투명 체크무늬 배경, 단색 배경 전환(검정, 회색, 흰색, 초록 크로마키), 픽셀 그리드 격자 토글.
- **스프라이트 맵 뷰어**: 우측 하단에서 텍스처 시트의 현재 프레임 위치를 실시간 바운딩 박스로 하이라이트.

### (4) 4개 국어 완전 실시간 전환 (i18n)
- 상단 언어 선택 즉시 전체 UI, 58종 애니메이션 목록, 카테고리 헤더, 의상/헤어 옵션명, 캔버스 타이틀까지 새로고침 없이 즉각 번역 갱신.

## 3. 핵심 아키텍처 및 소스 구조 (Architecture & Code Map)

단일 파일(`StardewFarmerPreview.html`) 내부에 모듈식으로 구조화되어 있습니다:

```
StardewFarmerPreview.html
│
├── <style> : 스타듀밸리 고유 목재/양피지 UI 테마 CSS
│   ├── .canvas-panel   : 반응형 프리뷰 캔버스 컨테이너 (그리드/체커보드)
│   ├── .control-panel  : 헤어/의상/색상 조절 사이드바
│   └── .anim-panel     : 58종 모션 카테고리 아코디언 및 버튼 그리드
│
├── <script> (데이터 및 i18n 사전)
│   ├── I18N            : ko, en, zh, ja 4개 국어 번역 딕셔너리 (모션명, UI 라벨, 카테고리)
│   ├── ANIMATIONS      : 58개 모션 정의 (프레임 인덱스 배열, 딜레이ms, 루프 여부, 좌우반전 플래그)
│   └── SAMPLES         : 내장된 바닐라 파머 베이스/의상 Base64 샘플 텍스처
│
├── <script> (핵심 렌더링 파이프라인)
│   ├── render()        : 캔버스 지우기 -> 신체 -> 바지 -> 셔츠 -> 헤어 합성 드로잉
│   ├── drawPart()      : 소스 스프라이트 좌표 추출, RGB 색상 틴트(Color Tint) 합성 및 렌더링
│   ├── update()        : requestAnimationFrame 기반 틱 루프 (RAF 폭주 방지 가드 탑재)
│   └── changeLanguage(): 활성 언어 딕셔너리 기반 실시간 DOM 및 UI 텍스트 일괄 갱신
│
└── <script> (이벤트 및 백그라운드 관리)
    ├── visibilitychange: 탭 비활성화/복귀 시 델타 타임(dt) 리셋으로 광속 재생 원천 방지
    └── File Drag & Drop: 커스텀 `.png` 리텍스쳐 파일 드래그 시 즉각 텍스처 오버라이드
```

## 4. 트러블슈팅 및 설계 결정 이력 (Gotchas & History)

### 1) 백그라운드 탭 방치 후 복귀 시 애니메이션 광속 재생 현상
- **원인**: 사용자가 다른 브라우저 탭을 보거나 창을 최소화했을 때 `requestAnimationFrame`의 호출 간격이 늘어나면서 델타 타임(`dt = ts - lastTime`)이 수만 ms까지 누적됨. 복귀 시 잔여 시간이 소진될 때까지 프레임이 초당 60회 연속 갱신됨.
- **해결책**:
  - `dt > 200ms`인 경우 지연 누적을 무시하고 `elapsed = 0`으로 강제 리셋.
  - `document.addEventListener('visibilitychange')` 및 `window.onfocus` 이벤트에서 `lastTime = performance.now()`로 동기화하여 완벽 차단.

### 2) 다국어 전환 시 특정 UI가 갱신되지 않고 멈추는 오류
- **원인**: `updateHairLabelUI()` 함수 내부에서 정의되지 않은 구버전 변수(`hairIndex`)를 호출하여 `ReferenceError` 발생. 이로 인해 `changeLanguage()` 루틴이 도중에 중단되어 이후의 바지/셔츠/옵션 텍스트 및 사이드바 재구축이 실행되지 못함.
- **해결책**:
  - 변수명을 `hairStyleIndex`로 정상화.
  - 캔버스 상단 타이틀 갱신 전용 함수 `updateAnimLabel()`을 신설하여 4개 국어 언어 변경 시 애니메이션 제목까지 실시간 동기화.

### 3) 도구/무기 스프라이트 분리 및 제거
- **결정 배경**: 바닐라의 복잡한 툴팁/무기 Z-Order는 손잡이와 날의 회전점(Pivot) 및 방향별 스프라이트 정렬이 모션마다 극단적으로 다름. 이로 인해 도구가 의상/신체/얼굴을 가려 본래 목적인 **리텍스쳐 도트 검수**를 방해함.
- **조치**: 프리뷰어 본연의 가치인 **"파머 외형 및 의상 모션 정밀 검수"**에 집중하기 위해 도구 오버레이를 배제하고 파머 순수 모션 58종에 집중하도록 정리함.
